# USDT0 on Stellar: friction log

Everything that slowed us down while building with USDT0 and LayerZero V2 on Stellar between 3 August and 7 October 2026. One row per distinct problem. "Owner" is who can make the next developer's life easier, not who is at fault. Status reflects 7 October 2026.

Companion to the Field Note: [USDT0-field-note.md](USDT0-field-note.md). Demo repo: https://github.com/kaankacar/stellar-layerzero-demos. Run logs with timestamps: [runs/](runs/).

Legend. Status: **open**, **fixed** (by us, in our code), **resolved** (upstream), **by design** (not a bug, but it needs to be written down). Owner: **LZ** (LayerZero Labs), **EV** (Everdawn Labs, USDT0), **SDF** (Stellar docs or tooling), **us** (our demo code).

## B. Writing an OApp on Stellar

| # | What happened | Symptom | Root cause | Fix or workaround | Status | Owner | Evidence |
|---|---|---|---|---|---|---|---|
| B1 | `#[oapp(custom = [receiver])]` compiled cleanly and exported no receive surface. | Inbound messages can never be executed. | The attribute removes the whole receiver, including `allow_initialize_path`. | Do not use `custom = [receiver]` unless you implement all of it. | by design | LZ | skill file L270 |
| B2 | A bare OApp `send` failed with ULN302 error `#1114`. | `InvalidOptions` after a successful quote. | Empty caller options went straight to the endpoint. The OFT calls `combine_options` internally; a bare OApp does not. | Call `Self::combine_options(env, dst_eid, msg_type, options)` before `__quote` and `__lz_send`. | fixed | us | commit [d8dc222](https://github.com/kaankacar/stellar-layerzero-demos/commit/d8dc222) |
| B3 | `__quote` panics without a peer; `set_peer` must be called by `authorizer()`. | Confusing panics during wiring. | Undocumented preconditions. | Set peers on both sides first, from the admin. | by design | LZ | skill file |
| B4 | Options encoding is undocumented for Stellar. | Hand-built bytes. | Type 3 options: `0x0003`, worker id `0x01`, size u16, option type `0x01`, gas u128 big-endian. | [options.ts](../../src/lib/layerzero/options.ts) | open | LZ | repo |
| B5 | The recipient and peer are raw 32-byte payloads, not strkeys. | Funds sent to the wrong bytes are gone. | The OFT disambiguates C versus G by checking whether the contract exists at delivery time. An undeployed or archived C recipient falls back to a G account nobody controls. Muxed M addresses do not fit in 32 bytes. | Decode with `StrKey.decode*` and confirm the contract exists before the source chain sends. | by design | LZ, EV | skill file L82 to L94 |
| B6 | Do not copy the CCTP pattern. | CCTP carries the recipient strkey as UTF-8 hook data; LayerZero does not. | Different standards. | Read B5. | by design | SDF | docs |
| B7 | The CLI needs a JSON-quoted hex string for `Option<BytesN<32>>` and can silently store `None`. | Peer appears unset after a successful command. | CLI argument encoding. | Quote the hex as a JSON string; read the peer back. | open | SDF | skill file |
| B8 | ZRO fee failures surface in two places with two different errors. | `ZroUnavailable` versus `ZroTokenUnavailable`. | Pay in XLM only. | `pay_in_zro: false`. | by design | LZ | skill file L272 |
| B9 | `FeePayer::Verified` must be used when the OApp already called `require_auth`. | Double auth prompt or failure. | The send path asks again otherwise. | See the Postcard contract. | by design | LZ | [postcard-oapp/src/lib.rs](../../contracts/stellar/postcard-oapp/src/lib.rs) |
| B10 | `#[contractevent]` names are snake_case on the wire. | Event filters miss `compose_sent`, `packet_sent`. | SDK naming. | Filter on snake_case topics. | by design | SDF | README caveats |

## D. Wallets and the EVM side

## E. USDT0 itself

| # | What happened | Symptom | Root cause | Fix or workaround | Status | Owner | Evidence |
|---|---|---|---|---|---|---|---|
| E1 | USDT0 has no testnet deployment. | Nothing to rehearse against. | Mainnet-only asset. | Build a mock that mirrors the admin model (locked issuer, SAC-manager admin, MintBurn OFT), label it loudly, and do one dust-sized real transfer. | by design | EV | [docs.usdt0.to deployments](https://docs.usdt0.to/technical-documentation/developer/usdt0-deployments) |
| E2 | The seventh decimal never leaves. | `quote_oft(10000001)` returns `amount_sent_ld 10000000`. | 7 local decimals, 6 shared, conversion rate 10. With a route fee the remainder is absorbed into the fee instead. | Always call `quote_oft` first and use its receipt as the floor. | by design | EV | [runs/run0-recon.log](runs/run0-recon.log) |
| E3 | Burn or lock is decided per leg. | "Burn and mint on both ends" is wrong for Ethereum. | Stellar's OFT is `MintBurn`; Ethereum's is an adapter that locks canonical USDT, `approvalRequired = true`. | Approve first on Ethereum; never promise symmetry. | by design | EV | run0 log |
| E4 | A G recipient needs a trustline before the message lands. | The most common inbound failure. | Classic asset rules. | Create the trustline first; or deliver to a contract. | by design | SDF | skill file L43 |
| E5 | No `home_domain`, so no `stellar.toml`; `name()` returns `CODE:ISSUER`. | SEP-1 validation fails, wallets show an ugly name. | Issuer configuration. | Supply the display name and icon yourself; pin the issuer. | open | EV | run0 log |
| E6 | Many assets share the code USDT or USDT0. | Copy-paste risk. | Open asset namespace. | Pin code and issuer and verify the SAC derivation equals `CBSJZEIO…`. | by design | SDF | run0 log |
| E7 | The issuer is revocable and clawback-enabled with master weight 0; the SAC admin is a contract owned by a OneSig multisig. | Listing teams need to know who can freeze. | Operator design. | Document it. | by design | EV | run0 log |
| E8 | Two fees in two denominations. | Numbers carried from one into the other. | The messaging fee is XLM stroops; the OFT fee is USDT0. | Keep them apart. Overpaying is refunded. | by design | LZ | skill file L174 |
| E9 | Never discover a route with a real slippage floor. | `SlippageExceeded` hides whether a route is expensive or broken. | Both quotes assert the floor. | Quote with 0, show the user, re-quote with their floor. | by design | LZ | skill file L172 |
| E10 | The messaging fee to Ethereum moved from 3.55 XLM on 10 September to 11.95 XLM on 7 October. | Documented numbers go stale fast. | Fees track gas and price. | Quote live, every time. | by design | LZ | run0 log |
| E11 | Peers, pause state, fee bps, rate limits and the DVN set are live configuration. | Five DVN operators in August, seven by late September. | Config changes without notice. | Read it live; the Inspector does. | by design | LZ, EV | run0 log |
| E12 | The experimental OFT list endpoint did not include a Stellar entry for USDT0 when checked. | Registry-driven tooling misses Stellar. | Metadata gap. | Hardcode the three Stellar addresses from docs.usdt0.to with a verification. | open | LZ, EV | [usdt0.ts](../../src/config/usdt0.ts) |
